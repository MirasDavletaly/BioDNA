# BioDNA — детекция рака груди классическим машинным обучением

Определяет наличие опухолевой ткани по профилю экспрессии генов и проверяет,
распознаётся ли **ранняя стадия (I–II)**. Каждый ген-маркер привязан к
**координатам в ДНК** (сборка hg38): хромосома, позиция, цитобанд.

**Без нейросетей.** Только scikit-learn: логистическая регрессия, SVM,
случайный лес, Extra Trees, градиентный бустинг, наивный Байес, k-NN и их
ансамбль. Ни torch, ни transformers, ни DNABERT в проекте больше нет.

---

## Данные

`TCGA-BRCA` (рак молочной железы), уровень 3, Agilent — log2-отношения:

| | Образцов | Генов |
|---|---|---|
| Норма (прилежащая ткань) | 61 | 17 814 |
| Опухоль | 529 | 17 814 |

Клинические стадии подтягиваются автоматически из **GDC API** по баркодам
TCGA (в самих файлах экспрессии их нет):

| Стадия | I | II | III | IV | неизвестна |
|---|---|---|---|---|---|
| Образцов | 89 | 298 | 110 | 13 | 19 |

Координаты генов берутся из **UCSC refFlat + cytoBand (hg38)**, устаревшие
символы генов разрешаются через синонимы **NCBI gene_info**
(`WISP1 → CCN4`, `PPAPDC1A → PLPP4` и т.д.) — благодаря этому локус
находится для **17 053 из 17 814** генов, а не для 14 472.
Все три источника скачиваются один раз и кэшируются в `data/annotation/`.
Без интернета пайплайн отработает тоже — просто без стадий и координат
(`python train.py --offline`).

## Почему цифрам можно верить

AUC = 1.000 выглядит подозрительно, поэтому в пайплайн встроены четыре защиты.

1. **Отбор генов внутри пайплайна.** `SelectKBest` обучается только на
   train-фолде. В прежней версии проекта отбор шёл по всей выборке — это
   утечка, которая сама по себе рисует AUC 1.000 на пустом месте.
2. **Разбиение по пациентам**, а не по образцам (`StratifiedGroupKFold`).
   У части больных в наборе есть и опухоль, и своя же прилежащая норма;
   случайный сплит растащил бы их по train/test, и модель училась бы узнавать
   пациента.
3. **Контроль батч-эффекта.** Нормы и опухоли частично разведены по разным
   плашкам (technical plates). Если оставить только 4 плашки, содержащие
   **оба** класса сразу (38 норма / 189 опухоль), CV ROC-AUC остаётся 1.0000 —
   значит различается ткань, а не партия реактивов.
4. **Победитель выбирается по кросс-валидации, не по тесту** — иначе тест
   перестал бы быть независимой оценкой.

Настоящая причина высоких цифр в другом: **опухолевая ткань молочной железы и
прилежащая нормальная ткань различаются по экспрессии очень сильно**. Это
известное свойство TCGA-BRCA, а не заслуга модели.

### Что этот проект НЕ делает

Задача решается на **ткани**: образец уже взят при биопсии или операции.
Это подтверждение диагноза и молекулярная характеристика опухоли, а не
скрининг по анализу крови. «Раннее выявление» здесь означает
«**ранняя стадия распознаётся не хуже поздней**», а не «рак виден до появления
клинических признаков». Для скрининга по крови (ctDNA, cfDNA) нужны другие
данные, и метрики там принципиально ниже.

## Запуск

```bash
pip install -r requirements.txt

python train.py                      # полный прогон, ~4 минуты
python train.py --n-genes 50         # панель из 50 генов
python train.py --target-sensitivity 0.99   # жёстче порог под скрининг
python train.py --offline            # без обращений в интернет
python train.py --no-early           # пропустить блок ранней стадии
```

Предсказание по обученной модели:

```bash
python predict.py --self-test                              # проверка на данных проекта
python predict.py --sample data/BC-TCGA-Tumor.txt --limit 5
python predict.py --sample my_samples.tsv --explain --out risk.csv
```

`--explain` показывает, по каким генам образец отклонился и где эти гены
лежат в ДНК. Входной TSV — в формате TCGA (строки = гены, столбцы = образцы);
транспонированный вариант распознаётся автоматически, недостающие гены
заполняются медианой обучающей выборки.

Модель выдаёт не только «да/нет», а калиброванную оценку риска и одну из трёх
зон: низкий риск / **серая зона** (нужно доисследование) / высокий риск.
Порог намеренно смещён в сторону чувствительности: пропущенная опухоль стоит
дороже ложной тревоги, которую снимает биопсия.

## Структура

```
data/
  BC-TCGA-Normal.txt / BC-TCGA-Tumor.txt   исходные матрицы экспрессии
  annotation/                              кэш: refFlat, cytoBand, gene_info, стадии
src/
  data_preprocessing.py   загрузка, чистка, метаданные образцов
  clinical.py             стадии TCGA через GDC API, разбор баркодов
  gene_annotation.py      координаты генов hg38 + синонимы символов
  models.py               зоопарк моделей, метрики, пороги, отбор маркеров
  visualization.py        10 графиков отчёта
train.py                  полный пайплайн обучения
predict.py                предсказание по сохранённой модели
models/biodna_model.joblib
results/                  REPORT.md, metrics.json, CSV-таблицы, графики
```
